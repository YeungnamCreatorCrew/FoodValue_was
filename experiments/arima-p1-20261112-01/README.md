# AutoARIMA 1차 비교(p1) 검증 제출

공식 실행 ID: `arima-p1-20261112-01`; config ID: `fe2fa17f`; 실행 커밋 `c6abef3`(브랜치 `feat/autoarima-model`).
모델 설명: [`model_comparison/autoarima/README_MODEL.md`](../../model_comparison/autoarima/README_MODEL.md).

**AutoARIMA는 검증 관문을 통과하지 못했다(1X 2O 3X 4O 5X).** 설정은 튜닝 목록 결과로 미리 골랐고, 검증 전체 결과를 보고 바꾸지 않았다. 최종 시험 구간은 쓰지 않았다.

## 선택 설정

| 항목 | 값 |
|---|---|
| 계열 구성 | (a) 달력일 계열, 앞채움 최대 7일 |
| 계절성 | 없음(`seasonal=false`) — 튜닝 목록에서 m=7과 비교 |
| 변환 | 로그(`exp(평균)`으로 되돌림) |
| 외생변수 | 요일 더미 6개(`calendar_exog="weekday"`) |
| 탐색 | `max_p=5, max_q=5, max_P=2, max_Q=2`, d·D 검정, `ic=aicc`, `stepwise=true`, `approximation=false`, `n_jobs=1` |
| 학습 창 | 최근 최대 1,825일, 주 첫 기준일에 차수·계수 학습, 주중엔 `forward`로 상태만 갱신 |

## 튜닝 기록(tuning_log.csv)

튜닝 목록(53개 기준일) 7회, 누적 10,285초(약 2시간 51분). 상한 40회, 권장 3시간 이내. 내부 차수 탐색 시간은 각 시도 시간에 포함된다. 후보 설정 파일은 `model_comparison/autoarima/p1_trials/`.

- 시도 4는 사용자 요청으로 한 번 중간에 멈췄다가(기록되지 않음) 처음부터 다시 돌렸다. 중단된 실행의 시간은 기록에 없다.
- 검증 전체 실행도 한 번 중간에 멈춰 결과를 버리고 이 실행으로 처음부터 다시 했다(설정·코드 동일).
- 계절 정확 우도 탐색(`approximation=false`, m=7)은 재학습 1회 20~40초로 시도 1회가 3시간을 넘어 후보에서 뺐다.

## 결측과 성공률

`OK=16793`, `NO_INPUT=287`. NO_INPUT은 모두 깐마늘 도매의 41개 기준일(2025-07-02 ~ 2025-08-28)이다. 원천 장기 결측(2025-06-25 ~ 07-31) 때문에 최신 관측이 7일보다 오래되었거나 v[d-28..d]에 빈 값이 남아 공통 로더가 입력을 만들지 않았다. policy는 이 점을 naive로 대체한다. 전체 행 기준 성공률은 약 98.32%이고, 관문 4의 공식 판정은 metrics의 평가 대상 성공률(99.2018%)을 따른다.

# v2 첫 결과 (2026-11-12, 클라우드 작업 환경, v1 스냅샷 + v2 추가 자료)

모두 XGBoost. "통합" = 10계열 통합 학습(`run_pooled`), "계열별" = v1 실행기(`run_backtest`, `config_p1.json` params).
평가는 v1과 같은 공통 평가기(policy macro MAPE). 같은 환경 안에서만 비교한다(Windows PC와는 소수 셋째 자리가 다를 수 있음).

- 시드에 따른 흔들림은 약 ±0.01%p. 반입량·다른 품목 가격의 차이(+0.02%p)는 잡음 수준, 주산지 날씨(+0.16~0.20%p)는 분명히 나쁨
- 주산지 날씨 52주는 모델 중요도의 49%를 차지하면서 성적은 떨어짐 → 날씨 이력으로 **계절을 외우는 과적합**
- 평년 대비 편차로 계절을 빼도 나아지지 않음

## 결론(현재까지)

1. **추가 자료(가락 반입량·주산지 날씨·다른 품목 가격)는 7일 뒤 전국 평균 가격 예측을 개선하지 못했다.** 넣을수록 나빠지는 경우가 많다.
2. **통합 학습은 계열별 학습과 비슷하거나 조금 낫다.** 튜닝 목록에서는 계열별이 0.02%p 낫고, 검증 전체에서는 통합이 0.06%p 낫다 → 큰 차이는 아님.
3. 성능을 끌어올린 것은 지금까지 **상대 시장 가격(MARKET)** 하나다.

## 다음 후보

- 반입량을 "도매 계열에만" 쓰기(소매는 반입량과 연결이 약함)

- 예측 기간이 더 긴 문제(2~4주 뒤)에서는 날씨·반입량이 더 쓸모 있을 수 있음 — 7일은 직전 가격이 지배적

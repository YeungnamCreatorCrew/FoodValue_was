# 분석 정의와 증거 범위

현재 분석 상태는 PLANNED이며 외부변수의 실측 효과는 아직 없다. 가설을 인과관계로 표현하지 않는다.
전체 실행 후 `metrics.json`, `result.json`, `diagnostics.jsonl`, `official_comparison.json`을 함께 검토한다.

## 공식 지표 및 추가 계산

공통 평가 대상은 실제 목표일 가격과 Naive가 있는 점이다. policy는 모델 실패점을 Naive로 대체한다.
model_only는 성공점만, common_success는 비교 실험 모두의 성공점만 사용한다.
MAPE·MAE·macro rMAE·Naive 대비 개선율·월 블록 bootstrap·채택 관문은 `tools.evaluate`의 정의 그대로다.
성공률은 `metrics.success_rate`이며 전체 predictions.csv의 OK 비율로 대체하지 않는다.
전체 행의 status/error_code 개수는 별도 실패 현황이다. 단위가 다른 MAE를 품목 간 평균하지 않는다.

추가 산식은 다음과 같다. 공식 파일의 소수 6자리 값을 사용하므로 미세한 반올림 오차가 있을 수 있다.

- p1 대비 변화(%p) = `p2 policy Macro MAPE − p1 policy Macro MAPE`. 음수가 개선이다.
- p1 대비 상대 개선율(%) = `(p1 MAPE − p2 MAPE) / p1 MAPE × 100`.
- Naive 대비 상대 개선율은 공식 policy.relative_improvement_pct 값을 사용한다.
- 계열/시장별 p1 변화도 같은 차이 산식이다. 품목별 macro MAPE는 그 품목의 소매·도매 계열 MAPE 단순 평균이다.
- p1 대비 개선·악화·동률 계열은 계열별 MAPE 차이가 각각 음수·양수·0인 개수다.
- 조합−각 단독 차이(%p) = `조합 MAPE − 해당 단독 MAPE`. 음수가 조합 우위다.
- 조합 대상은 같은 전체 범위·설정·데이터·코드로 완료한 5개 단독 중 p1보다 policy Macro MAPE가 낮은 묶음 전체다.
  개선은 조합 후보 조건이며 Naive 채택 관문 통과 또는 통계적 유의성의 동의어가 아니다.

## 표준화와 중복

매 FIT 진단은 열별 학습 누락 수·누락률·중앙값·전체 결측 여부·scaler mean/scale,
표준화 회귀계수 `beta_z`, 원 단위 계수 `beta_raw=beta_z/scale`을 제공한다.
이 파이프라인은 `z=(x−mean)/scale`이므로 원 단위 절편은 `intercept_z−Σ(beta_raw×mean)`이다.
표준화 계수는 열의 척도를 맞춘 조건부 연관성이지 인과 효과나 독립적인 중요도가 아니다.
표준화 제거 실험은 이번 범위에 없으며 계수만으로 표준화의 성능 기여도를 단정하지 않는다.

활성(학습 분산>0) 표준화 특징의 Pearson 상관 |r|≥0.9 쌍과 SVD 조건수를 기록한다.
이 임계값은 해석용 진단이며 특징을 삭제하거나 모델을 선택하는 규칙이 아니다.
조건수는 상수 열을 제외한 표준화 행렬의 최대/최소 특이값 비다. 수치적으로 특이하거나 활성 열이 없으면 null,
`condition_singular_or_empty=true`다. null을 낮은 공선성으로 해석하지 않는다.
현재 가격·lags·이동평균과 상대 가격 등의 중복은 상관쌍을 바탕으로 점검한다.
Ridge는 공선성 아래 계수를 분산 배분하므로 한 계수만의 크기/부호로 외부변수를 평가하지 않는다.

계수 안정성은 동일 계열·특징의 주별 표준화/원 단위 계수 부호와 범위·표준편차를 비교한다.
학습 창·표준편차·누락률이 바뀌므로 주별 coefficient 차이가 곧 모델 오류라는 결론은 피한다.
최종 유지/제외 결정은 공식 성능·성공률·공통 성공점 비교와 함께 내린다.

## 누락률과 선형 관계 한계

PREDICT 진단의 특징별 missing_counts는 7개 시점에서 실제로 대체한 입력 개수다.
학습 전체 결측 열은 관측 입력도 고정하므로 별도의 frozen_counts를 보고한다.
FIT 진단은 해당 주 학습 창의 누락률이며, 예측 자료의 누락률과 섞어 계산하지 않는다.
진단과 예측을 (series_id, origin)으로 연결해 누락 유무·주별 누락률 구간으로 나누고,
공통 평가 대상에 한하여 `tools.evaluate.summarize`로 policy/model_only 성능을 계산할 수 있다.
구간별 표본 수·계열 수·계절·시장 구성이 달라 비교 편향이 있을 수 있다. 결과는 관찰 연관성으로 기술한다.

품목별 효과 차이는 가격 단위, 재배·유통 주기, 작형 전환, 외부변수 누락, 발표 지연과 중복성에 대한
가설을 먼저 적고 계열별·소매/도매·계절·horizon·kind_cross 공식 세부 결과와 진단으로 확인한다.
원인이 확인되지 않으면 '가능한 설명, 미검증'으로 남긴다. 날씨 임계값, 환율 전달 시차, 명절 비대칭처럼
선형 회귀가 포착하지 못할 수 있는 관계는 이번 모델의 한계이며 새 비선형 특징을 몰래 추가하지 않는다.

회고 스냅샷의 원천 수정 이력 미재현, 미래 외부변수의 실측값 미사용, 생산량 공개 지연 가정,
검증 데이터로 묶음을 고른 선택 편향도 최종 보고서의 한계에 포함한다.

# Ridge p2 결과 해석과 후속 판단

이번 스냅샷에서는 MARKET이 가장 좋은 후보였지만, Naive를 대체할 근거는 확보하지 못했다. MARKET의 Policy Macro MAPE는 4.940629%로 p1보다 0.119842%p, 상대 2.368199% 개선됐다. 그러나 Naive 4.912547%보다 0.028082%p 높고, Macro rMAE도 1.001712다. 모든 실험은 관문 1X·2X·3X·4O·5X로 공식 채택 기준을 통과하지 못했다.

아래의 수치는 실제 측정이고, 설명 가설은 별도로 표시했다. 상세 값은 [전체 분석 JSON](analysis.json), [계열 비교](series-comparison.csv), [계수·결측 진단](feature-diagnostics.csv), [최종 주 상관](latest-correlations.csv)에 연결된다.

## MARKET: 개선이 소매에 집중됐다

측정 결과 소매 Macro MAPE는 p1의 4.768998%에서 4.499174%로 0.269824%p 낮아졌다. 도매는 5.351944%에서 5.382085%로 0.030141%p 높아졌다. 전체 개선 계열과 악화 계열은 각각 5개이며, Naive를 이긴 계열도 5개로 과반 기준 6개에 못 미쳤다.

큰 개선은 무 소매 −0.605171%p, 배추 소매 −0.406763%p, 대파 소매 −0.392782%p였다. 이 세 계열만의 Macro 변화 기여 합계는 −0.1404716%p로, 다른 계열의 악화가 일부 상쇄해 최종 −0.119842%p가 됐다. 따라서 “모든 품목·시장에 고르게 유효하다”는 해석은 맞지 않는다.

기존 가격 특징과의 중복도 측정됐다. 마지막 주 학습 표본에서 무 도매 counter_price와 mean28의 Pearson r은 0.920306, 배추 도매 counter_price와 lag7은 0.912541, 대파 도매 counter_price와 mean28은 0.911402였다. 주별 FIT 530개 중 lag7–counter_price의 |r|≥0.9가 155개, mean7 및 mean28–counter_price가 각각 153개였다. 이 수치는 각 FIT의 계열·시점별 반복 관측 수이며 독립 표본 530개를 뜻하지 않는다.

가능한 설명은 상대 시장 정보가 소매의 기존 자기 가격 특징에 추가 설명력을 주는 반면 도매에는 중복 정보가 더 많았다는 것이다. 다만 상관과 오차 차이만으로 도매 가격이 소매 가격을 인과적으로 선도한다고 결론 내리지는 않는다.

## NATIONAL_WEATHER: 무 계열 악화와 기상 특징 중복

MAPE는 5.143822%로 p1보다 0.083351%p 악화됐다. 무 도매 +0.670542%p와 무 소매 +0.351578%p가 Macro를 합계 +0.102212%p 높였고, 배추 소매 −0.169527%p 등의 개선이 일부 상쇄했다. 양파 소매·도매도 개선됐으나 전체 평균을 낮추지는 못했다.

추가 기상 특징은 학습·예측에서 결측이 모두 0이므로, 이번 악화를 중앙값 대체가 작동한 결과로 설명할 수 없다. 강수 누적과 호우 지수의 |r|≥0.9는 530개 FIT 모두에서 관측됐다. 마지막 주 양파 도매의 평균 기온과 기존 계절 cos 특징의 상관은 −0.855622였다. 이 결과는 기상 특징끼리의 중복과 계절 정보와의 겹침을 보여주지만, 중복이 성능 악화의 유일한 원인임을 증명하지는 않는다.

배추 도매 nat_temp_mean7의 표준화 계수는 주별 −135.71901~76.84081 범위에서 부호가 7회 바뀌었다. 학습 창과 표준화 통계가 바뀌므로 부호 변동을 곧 인과 효과의 반전이나 모델 오류로 보지 않는다. 전국 평균이 지역별 기상, 가격 반응 시차, 비선형 임계 반응을 충분히 설명하지 못했을 가능성은 미검증 가설이다.

## EVENT와 MACRO: 낮은 중복이 성능 개선을 보장하지 않았다

EVENT는 5.200425%로 9개 계열에서 악화됐다. 특히 배추 도매 +0.564142%p, 대파 도매 +0.372671%p, 배추 소매 +0.206075%p가 컸다. 추가 EVENT 특징과 다른 활성 특징 사이에 |r|≥0.9인 쌍은 기록되지 않았다. 따라서 모든 성능 저하를 높은 다중공선성 하나로 설명하는 것은 근거가 없다. 명절 전후 효과의 품목 차이·비대칭·가격 수준에 따른 반응을 이번 고정 선형 특징이 충분히 표현하지 못했을 가능성은 가설이다.

MACRO는 5.085541%로 8개 계열에서 악화됐고, 도매 변화 +0.045523%p가 소매 +0.004617%p보다 컸다. 대파 도매 +0.111981%p가 가장 큰 악화였다. MACRO에서도 |r|≥0.9인 외부 특징 관련 쌍은 없었고 외부 특징 결측도 0이었다. 환율이 경제적으로 무관하다는 결론은 내릴 수 없으며, 현재 7일·28일 환율 변화와 고정 7일 가격 예측의 선형 연결이 이 Validation에서 개선을 주지 않았다고 해석한다.

## PRODUCTION과 조합: 단독의 작은 개선은 조합에 더해지지 않았다

PRODUCTION은 5.043419%로 p1 대비 0.017052%p, 상대 0.336965% 개선됐고 6개 계열이 개선됐다. 큰 변화는 대파 도매 −0.078646%p, 무 도매 −0.044731%p, 무 소매 −0.039565%p였다. 추가 생산량 특징은 실제 FIT/PREDICT에서 결측이 없었다.

MARKET과 PRODUCTION 두 묶음이 p1보다 낮아 사전 조건대로 조합했다. 조합 4.942954%는 PRODUCTION 단독보다 0.100465%p 좋지만 MARKET 단독보다 0.002325%p 나빴다. PRODUCTION 단독의 개선이 MARKET 위에 가산되지는 않았다. MARKET에 생산량을 더했을 때 무 소매는 3.895722%에서 3.939253%로, 무 도매는 9.031133%에서 9.094795%로 악화됐다. 대파 소매·도매와 배추 소매·도매는 반대로 개선됐다. 작은 전체 차이 안에도 품목별 상쇄가 있었다.

Ridge는 열이 추가되면 기존 열의 계수도 함께 다시 구한다. 따라서 단독 생산량 계수를 그대로 기존 MARKET 예측에 더하는 모델이 아니다. 연간 생산량의 낮은 갱신 빈도, 공개 지연, 가격 특징과의 중복은 가능한 설명이며 이번 실험은 그 원인들을 각각 분리해 검정하지 않았다.

## 결측 대체의 실제 영향 범위

MARKET에서만 외부 특징 결측 대체가 실제로 작동했다. 학습 표본 노출 기준 결측률은 counter_price 0.1264%, target_counter_ratio 4.3032%, counter_change7 0.1784%, counter_change28 0.2347%였다. 성공 예측의 특징 셀 기준으로는 각각 0.9170%, 2.5844%, 1.1255%, 1.7090%였다. 조합의 MARKET 열도 같은 원천 결측을 사용했다. 전체 결측 특징이 발생한 FIT는 모든 실행에서 0개였다.

MARKET의 외부 특징 결측이 있는 공식 평가점 397개에서는 Macro MAPE 7.408814%, 같은 점의 p1 대비 변화 −0.432734%p였다. 결측 없는 10,788점에서는 4.921445%, p1 대비 −0.121038%p였다. 결측 그룹의 원시 점수가 더 높다는 사실과 p1 대비 개선이 더 크다는 사실을 구분해야 한다. 두 그룹은 계열 수·계절·가격 변동 구성이 다르므로 이 비교가 중앙값 방식의 인과 효과나 대체 방식 간 우열을 뜻하지는 않는다. 대체 방식 변경 실험은 하지 않았다.

모든 실험에서 NO_INPUT은 287행, OK는 16,793행이었다. 공식 평가 대상에서는 실패 90점, 성공 11,185점으로 성공률 99.2018%다. 287행 전체를 평가 대상 실패로 바꾸면 기준이 달라지므로 그렇게 계산하지 않았다. 이 실패는 기존 깐마늘 도매 공백이며 신규 모델 FIT_FAILED, PREDICT_FAILED, INVALID_VALUE, TIMEOUT은 없었다.

## 표준화·계수·신뢰성 해석

학습 표본만으로 구한 중앙값과 StandardScaler를 저장해 예측에 재사용했다. 표준화 계수 beta_z는 해당 열의 학습 표준편차 단위 변화에 대한 조건부 선형 연관이며, 원 단위 계수는 beta_z/scale이다. 계수 크기를 가격 단위가 다른 품목 사이의 중요도로 직접 비교하지 않는다. 계수 부호 변경 횟수는 절댓값 1e-12 이하를 제외하고 주별 순서에서 집계했다.

활성 표준화 행렬 조건수의 FIT 평균은 CONTROL 72.919139, MARKET 79.167077, NATIONAL_WEATHER 76.486069, EVENT 73.274732, MACRO 73.059455, PRODUCTION 73.478845, 조합 79.732517이었다. 조건수 평균만으로 안정성이나 성능을 판정하지 않으며, 원래 가격 lag·이동평균 사이에도 중복이 있다. 이번 활성 행렬에서 수치적으로 특이하거나 빈 것으로 기록된 FIT는 없다.

CONTROL의 저장 원시 예측·후처리·상태·오류 코드, 평가점, 실제 성능 지표가 p1과 일치했다. 80개 테스트와 소스 검토에서는 새로운 누수·데이터 무결성·평가 기준 문제를 발견하지 않았다. 이것이 원천 데이터의 과거 수정 이력까지 완전히 복원했음을 뜻하지는 않는다. 공식 bootstrap 관문은 Naive 대비 결과이고, 별도의 p1 대 p2 차이 신뢰구간을 계산한 것은 아니다. Validation에서 후보를 고른 선택 편향도 있다.

## 후속 유지·제외 판단

- MARKET의 4개 변수는 고정 묶음으로 후속 비교 후보에 유지한다. 개별 열을 선별할 근거는 이번 실험에 없으며, 현재 결과를 공식 Test 채택으로 표현하지 않는다.
- PRODUCTION은 단독의 작은 개선을 기록하되 현재 MARKET에 추가할 근거는 부족하다. 조합의 추가 개선이 없었으므로 단순한 MARKET을 우선 후보로 둔다.
- NATIONAL_WEATHER·EVENT·MACRO는 현재 스냅샷·고정 Ridge의 p1 대체 후보에서는 제외한다. 다른 모델·시차·새 데이터에서의 효과까지 부정하는 결론은 아니다.
- 가락시장·주산지 날씨는 새 스냅샷 수령 후 별도 버전에서 원천 공개시점·품목·시장·지역·단위·결측·수정 이력을 검증하고, 동일 기간·계열의 새 base CONTROL부터 비교한다. 이번 스냅샷 결과와 섞지 않는다.

추가 튜닝·개별 변수 선택·상호작용 추가·평가 정책 변경·공식 Test는 수행하지 않았다.

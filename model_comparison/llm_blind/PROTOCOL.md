# LLM 블라인드 예측 실험 — 고정 절차 (eval 첫 프롬프트 전에 작성)

- 예측자: Claude Opus 5.5 (대화 안에서 직접 판단, 코드·통계 모델 사용 안 함)
- 입력: `make_prompt.py`가 만든 기준일별 프롬프트만. 자기 계열 ≤ d, 상대 시장·기상 ≤ d−1, KREI 월보 available_from ≤ d 23:00, 연도 비공개
- 출력: 계열별 D+1~D+7 현재가 대비 % 변화. 0 = naive
- 순서: 기준일 k 예측 잠금(SHA-256, `lock.log`) → k+1 프롬프트 생성. 채점은 eval 전체 잠금 후 1회
- eval 기준일: 검증 구간 튜닝 목록(origins_tune.csv)에서 4주 간격 14개 (`origins.json`). 최종 시험 구간(2025-11-10~)은 쓰지 않음
- shrink = 1.0 (dev에서 0.5보다 좋았음: 3.230% vs 3.264%, naive 3.401%)

## dev(2023-11~2024-08, 4개 기준일)에서 얻어 eval에 적용하는 판단 규칙
1. 기본은 0%. 근거가 있을 때만 움직인다.
2. 소매: 도매 추세(상대 시장 4주 변화, 최근 1~2주 흐름)와 과거 같은 시기 흐름이 같은 방향이면 따라간다. 크기는 dev에서 과소였으므로 h7 기준 ±3~6%까지 허용.
3. 도매: 일별 잡음이 크다. 하루 급등·급락 뒤 되돌림 예측은 하지 않거나 작게. 추세 추종도 작게(±0~2.5%).
4. KREI 전망 가격은 기준 시장이 달라 수준 비교 금지. "전월 대비 상승/하락" 같은 방향 표현만 참고.
5. 깐마늘 도매처럼 거의 고정된 계열은 0.

기준: `model_comparison/MODEL_TRAINING_STANDARD.md` (기준서 v1). 고정 항목(스냅샷·계열·기준일·주 1회 재학습·학습 창 1,825일·스레드 4·평가)은 기준서를 따르고, 여기에는 부록 A의 "자유" 항목에서 정한 것과 그 근거를 적는다.

## 1. 모델 구성

| 항목 | 선택 | 이유 |
|---|---|---|
| 목표 변환 | `log_ratio`: log(y_{d+h} / current) | 계열마다 가격 수준이 달라도 "현재가 대비 변화"로 같은 척도. 예측은 current·exp(ẑ) |
| 전략 | `direct_per_horizon`: h=1..7마다 부스터 1개 (`horizon` 특징 제외) | 통합(pooled)보다 튜닝 목록에서 확실히 나았음(시도 6) |
| 특징 | base_v1 15개 → `relative_features`로 원 단위 열을 current 대비 비율로 바꾸고 `current` 자체는 뺌 | 아래 1.1 |
| 모델 크기 | 깊이 2, 잎 4, 나무 60, 학습률 0.05, 갈래당 최소 표본 100, L2 10, 배깅·열 샘플링 없음 | 큰 모델(시도 1)이 naive보다 나빴음. 작게·강하게 규제할수록 좋아짐 |
| 조기 종료 | 끔 | 고정 반복 수가 튜닝으로 정해져 있고, 재학습마다 반복 수가 달라지지 않게 |
| 결정성 | `deterministic`·`force_row_wise`·`num_threads=4`·`seed=42`를 코드에서 강제 | §6 재현성. 같은 시드면 예측이 비트 단위로 같음(테스트) |

### 1.1 상대 특징 (`relative_features: true`, `keep_current: false`)

- `lag1·lag7·lag14·lag28·mean7·mean28` → x / current − 1, `volatility7` → volatility7 / current. 나머지 특징은 그대로.
- **정보를 추가하지 않는다.** 같은 15개 특징을 기준일 d 시점 값만으로 결정적으로 바꾼 것이라 시점 규칙(§3.1)에 영향이 없다.
- 이유: 트리는 학습 범위 밖 가격 수준으로 외삽하지 못한다. 가격이 처음 보는 수준으로 오르면 원 단위 특징은 학습 때 본 적 없는 값이 된다. 비율로 바꾸면 "최근 7일 평균보다 3% 높다" 같은 규칙을 수준과 무관하게 쓸 수 있다.
- `current`(원)를 빼면 모델이 가격 수준에 전혀 의존하지 않는다: 가격 전체를 k배 하면 예측도 정확히 k배(테스트 `test_relative_features_make_predictions_scale_with_price_level`).
- **2차 외부변수에는 적용하지 않는다.** 1차 params를 고정하기 때문에 MARKET의 `counter_price`는 원 단위 그대로 들어간다(§4 한계).

### 1.2 결측 처리

- 기준서 §5.2: 외부값이 비면 NaN으로 두고 채우지 않는다.
- LightGBM 기본 결측 처리(`use_missing=true`)를 그대로 쓴다. 나무를 나눌 때 NaN을 어느 가지로 보낼지 학습 표본에서 정한다. 별도 대체값·결측 표시 열은 만들지 않는다.
- base_v1 특징은 로더가 v[d−28..d]에 빈 값이 있으면 그 기준일을 만들지 않으므로(§5.1) NaN이 없다. 그 기준일은 실행기가 `NO_INPUT`으로 기록한다(깐마늘 도매 2025-06-25 ~ 07-31 원천 결측, 287행).
- 예측 입력의 외부변수가 모두 NaN이어도 예측이 나오는지 테스트한다(`test_nan_in_extra_features_is_accepted`).

## 3. 결과

검증 기준일 2024-11-01 ~ 2025-10-31, policy macro MAPE, naive 4.913%. 관문 번호는 기준서 §8.4.

| 실험 | 입력 | MAPE | naive 대비 | 계열 승 | 관문 미달 |
|---|---|---|---|---|---|
| lgbm-p1-20261111-01 | base_v1 | 4.769% | +2.93% | 5/10 | 1, 3 |
| lgbm-p2-20261111-01 | +MARKET | **4.693%** | **+4.47%** | **8/10** | 1 |
| lgbm-p2-20261111-02 | +NATIONAL_WEATHER | 4.790% | +2.49% | 5/10 | 1, 3, 5 |
| lgbm-p2-20261111-03 | +EVENT | 4.782% | +2.65% | 5/10 | 1, 3, 5 |
| lgbm-p2-20261111-04 | +MACRO | 4.793% | +2.44% | 5/10 | 1, 3, 5 |
| lgbm-p2-20261111-05 | +PRODUCTION | 4.767% | +2.96% | 5/10 | 1, 3 |
| lgbm-p2-20261111-06 | +MARKET+PRODUCTION | 4.694% | +4.45% | 8/10 | 1 |

- 1차는 채택 후보 아님(관문 1·3). XGBoost 1차(4.855%)와 상대 차이 1.8%로 동률 범위(§8.5).
- 튜닝 목록 +4.87% → 검증 +2.93%: 튜닝 목록에서 고른 설정의 선택 낙관.
- 2차에서 효과가 분명한 묶음은 MARKET 하나. PRODUCTION은 1차보다 0.001%p 낮아 규칙상 "효과 있음"이 됐을 뿐 사실상 같다.
- 성공률: 평가 대상 기준 99.20%(공식, §8.3). 전체 예측 행 기준 98.32% — 차이는 깐마늘 도매 원천 결측 `NO_INPUT` 287행.
- 실행 시간: 검증 전체 1회 약 42~45초(학습·예측만, 10계열 × 재학습 53회 × 부스터 7개).

### 참고: 등락 방향 (공식 지표 아님)

lgbm-p2-20261111-01 기준, 실제 가격이 움직인 점에서 방향 적중 62.5%(1차 59.8%). 실제 변동이 클수록 잘 맞고(10% 이상 72%), 2% 미만은 57%. 예측 변동폭 중앙값 1.1%로 실제(2.6%)의 절반 이하 — 방향은 대체로 맞지만 폭을 작게 내는 보수적 모델이다.

## 4. 한계

- `counter_price`(MARKET)는 원 단위 그대로 들어간다. 1차 params 고정 규칙 때문에 변환을 추가하지 않았다. `target_counter_ratio`·변화율은 이미 비율.
- MARKET의 상대 시장 가격·변화율은 소매·도매 작형 차이를 포함한다(§5.2).
- 날씨 묶음이 효과가 없던 것은 입력 구조 영향이 크다고 본다: 전국 평균만, 최근 7·28일 집계만, 예측 범위 7일. 날씨가 출하량을 통해 가격에 반영되는 시차(수 주~수 개월)를 담지 못한다. 주산지·시차 특징은 기준서 v1 범위 밖이다.

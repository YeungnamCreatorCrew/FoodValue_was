# 구조적 가격 전달 모델 (struct) — 구현 노트

설계 정본은 `PRD.md`다. 이 문서는 (1) PRD와 다르게 구현한 점, (2) 도매 표현 정정을 적는다. 변형별 결과 표와 최종 파라미터 표는 C4에서 채운다.

## 1. PRD와 다르게 구현한 점
- **전달 항은 log1p(counter_change)**: `counter_change7/28`(변화율)에 log1p를 씌운 값을 열로 쓴다. (momentum 항도 log1p(change7))
- **열 RMS 정규화, 절편 없음**: 각 항 열을 열별 RMS로 나눈 뒤 최소제곱을 푼다. 절편과 중심화가 없다. 계수는 원 단위로 되돌려 보고한다.
- **λ는 합 형태**: `||y - Zw||^2 + λ||w||^2` (평균이 아니라 합 제곱 오차에 대한 L2).
- **선택 손실은 MAPE**: λ와 k_h는 내부 검증 구간(학습 표본 마지막 20%)에서 가격 MAPE로 고른다.
- **purge**: 내부 80/20 분할에서 목표일(기준일 + h)이 분할 경계를 넘는 표본은 학습 쪽에서 뺀다.
- **y_clip = 1.0, 비유한 값은 None**: 로그 변화율 예측을 [-1, 1]로 자른다. 예측이 NaN·무한이면 current로 대체하지 않고 None을 반환한다(실행기가 실패로 기록하고 채점에서 naive로 대체).
- **학습 창 경계의 계절 항**: 학습 창(최대 1,825일)의 첫 해 표본은 1년 전 가격이 창 밖이라 계절 비교 연도가 빠진다(그 표본의 계절 항 = 0, 빠진 연도는 가중 재정규화). 학습 창을 줄이면(730·1,095일) 이 영향이 커진다.
- **`retail_k_grid`(탐색 변형)**: 소매 계열만 k 후보를 넓힌다(기본 None = `k_grid`와 같음, 허용 [0, 3]). PRD §4.3은 k ∈ [0, 1]로 정했으나, 이는 계획 담당(0d)이 정한 탐색 변형이다. 도매는 기존 격자를 쓴다. 기본값에서 예측이 바뀌지 않음은 골든값 테스트(`test_golden_tune_predictions_unchanged`, t01·t04 저장 결과와 비교)로 확인했다.
- **축소 실행은 정확도를 내지 않는다(step 0)**: `--month`/`--series` 실행은 `predictions.csv`, `run.log`, `status_summary.json`(상태별 개수·시간)만 쓰고 MAPE·rMAE·naive 비교는 계산하지도 출력하지도 않는다. `score.py`도 이런 폴더의 채점을 거부한다.
- 1% 규칙은 PRD §13의 대칭 규칙((a) 상대 1% 이상 개선, (b) 더 단순하면서 상대 1% 미만 악화)으로 적용했다.

## 2. 도매 표현 정정
"도매는 사실상 naive"라는 표현은 **양파·깐마늘·무 도매에만** 해당한다. 대파 도매와 배추 도매는 계절 항을 실제로 쓴다. 근거는 기본형(t01_v0)을 튜닝 기준일의 주 1회 재학습 53번마다 맞춰 본 결과다(k_h > 0이 한 번이라도 있던 재학습 수 / 평균 k).

| 도매 계열 | k_h > 0인 재학습 | 평균 k | 계절 계수 c 부호 | 해석 |
|---|---|---|---|---|
| 2 대파 | 49 / 53 | 0.24 | 전부 + | 계절 항을 실제로 씀(그래도 tune에서 naive보다 −0.70%) |
| 9002 배추 | 53 / 53 | 0.60 | 전부 + | 계절 항을 실제로 씀(naive 대비 +0.19%) |
| 9 깐마늘 | 16 / 53 | 0.21 | 30%가 − | 대부분 naive |
| 7 양파 | 18 / 53 | 0.01 | 전부 − | 사실상 naive |
| 9012 무 | 12 / 53 | 0.01 | 전부 + | 사실상 naive |

- 2025-06-02 한 날짜만 보면 대파 도매(k_h 전부 0)도 naive처럼 보이지만, 위 53회 전체로는 대파 도매가 계절 항을 쓴다. 한 날짜 표로 일반화하지 말 것.
- 도매 계열이 naive와 같거나 약간 나쁜 것은 계절 항이 도움이 되지 않아서이지, 항이 꺼져 있어서가 아니다(양파·깐마늘·무 도매 제외).

### 3.3 §14 보정: 전체 macro 판정의 희석
- t04·t11처럼 소매 항만 바꾸는 변경을 전체 10계열 macro로 판정하면 효과가 도매 5계열 때문에 약 절반으로 희석된다. 그래서 t01→t13의 누적 악화는 전체 macro로는 +0.54%(4.4732 → 4.4973)로 1% 아래였지만 소매만 보면 +1.34%(4.0628 → 4.1174, naive 대비 개선 6.32% → 5.06%)로 1%를 넘었다.
- 보정(§14): 소매 항만 바꾸는 변경은 소매 macro로 판정하고, (b) 누적 악화가 1%를 넘으면 이후 (b) 채택은 무효로 하며, 학습 창 축소·격자 확대는 단순화로 보지 않는다.
- 소급 확인 1회(t18): 소매 macro가 t13 4.117355% → t18 4.062811%로 상대 1.325% 개선되어 (a)로 최종을 t18로 정했다. t18의 소매 계열별 수치는 t01과 같고, 전체 macro 4.4701%는 t01(4.4732%)과 거의 같다.
- 이 판정 규칙은 t18 실행 전에 PRD §14에 고정해 두었다.

### 3.4 남은 22회를 쓰지 않은 이유
자체 예산 40회 중 18회만 썼다. 시도 간 차이(4.464~4.562)는 53개 기준일 잡음 범위 안이고, 1% 규칙 안에서는 단순한 쪽이 더 낫다고 판단했다. 이 범위에서 더 탐색하면 튜닝 목록에 맞춰 과적합할 위험만 커지므로 계획(0d)이 C4에서 동결하고 나머지를 남겨 두기로 했다. 도매를 계열별로 고르는 추가 탐색도 같은 이유로 하지 않는다.

### 3.6 도매는 설계상 naive
도매 5계열은 항이 없는 naive라 계열 MAPE가 naive와 같고, "naive보다 낮다"는 계열 승은 엄격 부등호라 도매는 0승이다. 따라서 기준서 §8.4의 G3(계열 승 6/10 이상)는 최대 5/10이라 **구조적으로 도달할 수 없다**. G5(부트스트랩 하한 > 0)와 +5% 기준(G1)도 도매가 0%인 만큼 전체 평균에서 희석된다. 이 결과는 설계 결과로 그대로 보고한다.

### 3.7 소매 전용 수치는 사전 등록한 보조 지표
소매 5계열(1, 8, 10, 9001, 9011)의 macro MAPE·naive 대비·승/5·월 블록 부트스트랩은 검증 실행 전(2026-11-24)에 정의한 2차 지표다(`compare.py`, `C5_REPORT_TEMPLATE.md`). 사후 선택이 아니다. 주 지표는 전체 10계열 policy macro MAPE다.

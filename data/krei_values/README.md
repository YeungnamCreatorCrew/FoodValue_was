# KREI 관측월보 추출값 (krei_report_value)

KREI 관측월보 PDF에서 수치를 뽑은 결과를 호마다 JSON 파일 1개로 둔다.
추출기(로컬 Claude 백필, 운영 Gemini, 정규식)와 관계없이 **같은 형식, 같은 규칙**을 쓴다.
Gemini 프롬프트도 이 문서를 그대로 쓴다. 규칙을 바꾸면 `extractor_version`을 올린다.

- 파일 위치: `data/krei_values/{묶음코드}/{pdf_id}.json` (예: `OVR0000000036/8780.json`)
- 적재: `uv run python -m app.krei_values data/krei_values/OVR0000000036/*.json`
  - 원본 호(`external_observation`, `KREI`/`MONTHLY_REPORT`)가 먼저 수집돼 있어야 한다: `uv run python -m app.krei_monthly`
  - `published_at`은 원본 호에서 복사한다. JSON에 적지 않는다.
  - **한 파일 = 그 호의 전체 사실.** 다시 적재하면 같은 사실은 갱신하고, 파일에 없는 기존 행은 지운다.
  - `pdf_sha256`(추출에 쓴 PDF의 SHA-256)과 같은 PDF의 원본 호 버전에만 붙는다. KREI가 PDF를 고쳐 올렸으면 다시 추출해야 한다.

## 파일 형식

`unmapped`(선택)는 문서에 있었지만 이 스키마에 없어 뽑지 않은 데이터를 적는 곳이다. 적재되지 않는다.
여러 호에서 자주 나오는 항목을 모아 스키마 확장 여부를 정하는 근거로 쓴다(예: 수급 단계, 산지가격, 수출량).

```json
{
  "source_record_key": "OVR0000000036:8780",
  "pdf_sha256": "4dc5138b938edb63006986e46b23dbf72f2081806227656b3ce7bd5b8889866a",
  "extractor": "claude-opus-5-5",
  "extractor_version": "v1",
  "values": [
    {"item_name": "대파", "crop_type": null, "metric": "SHIPMENT", "kind": "OUTLOOK",
     "target_start": "2026-11-01", "target_end": "2026-11-30", "basis": "PREV_YEAR",
     "value": 1.5, "unit": "%", "direction": "UP",
     "evidence": "11월 출하량 : 단수 증가로 전년 대비 1.5% 증가"}
  ],
  "unmapped": [
    {"item_name": "양파", "what": "수급 단계(범주형)", "evidence": "수급가이드라인 '안정' 단계"}
  ]
}
```

| 필드 | 규칙 |
|---|---|
| `item_name` | KREI 품목명 그대로: `대파`, `양파`, `마늘`, `배추`, `무` (실험 품목만. 건고추·쪽파 등은 뽑지 않음) |
| `crop_type` | 같은 품목 안의 구분. 작형은 **KREI 표기에서 품목명을 뺀 것**(가을배추→`가을`, 겨울배추→`겨울`, 가을일반무→`가을일반`, 고랭지배추→`고랭지`, 봄무→`봄`). 우리 DB 작형명(`월동` 등)으로 바꾸지 않는다(연결은 로더에서), 마늘 유형(`난지형`, `한지형`, `깐마늘`), 양파 숙기(`조생종`, `중만생종`), 수입 형태(`신선`). 품목 전체면 `null`. 수입량은 문서가 "신선○○ 수입량"이라 하면 `신선`, 여러 형태를 환산한 합계면 `null` |
| `metric` | `PLANTED_AREA` 재배·정식·파종·재배(의향)면적 / `SHIPMENT_AREA` 출하면적 / `YIELD` 단수 / `PRODUCTION` 생산량 / `SHIPMENT` 출하량 / `ARRIVAL` 도매시장 반입량 / `STOCK` 재고량 / `IMPORT` 수입량 / `WHOLESALE_PRICE` 도매가격 / `RETAIL_PRICE` 소매가격 |
| `kind` | `ACTUAL` 이미 지난 기간의 실적·조사값(예: "10월 도매가격", "10월 말 기준 재고량", 지난달 수입량) / `OUTLOOK` 전망. **아직 수확이 끝나지 않은 작기의 면적·단수·생산량은 모두 `OUTLOOK`**(예: "가을배추 생산량 … 전망" 아래의 재배면적) |
| `target_start`~`target_end` | 값이 가리키는 기간. 월이면 그 달 1일~말일. "10~12월"이면 10-01~12-31. 연산(예: "2027년산")은 그 해 01-01~12-31. **작형 단위 값(가을배추 생산량 등)에 연산이 적혀 있지 않으면 호 발행 연도**의 01-01~12-31 |
| `basis` | `LEVEL` 절대값 / `PREV_YEAR` 전년 대비 / `NORMAL` 평년 대비 / `PREV_MONTH` 전월 대비 |
| `value` | 문서에 **적힌 숫자만**. 계산해서 만들지 않는다(예: "전년(1,050원) 대비 상승"에서 증감률을 계산하지 않음 → `value: null`, `direction: "UP"`). 감소·하락은 음수. "약 800원 내외"는 800 |
| `value_low`/`value_high` | 범위로 적힌 경우("1,330~1,390원") 둘 다. `value`는 비우면 중간값으로 채워진다 |
| `unit` | `LEVEL`: `원/kg`, `원/600g`, `원/10kg`, `톤`, `ha`, `kg/10a` 등 문서 단위. **"천 톤"·"만 톤"은 톤으로 환산**(41만 톤 → 410000, 표에 정확한 값이 있으면 표 값 우선). 비교 기준이면 `%` (또는 `%p`) |
| `direction` | `UP` / `DOWN` / `FLAT`. **문장 기준**으로 적는다: 증가·상승 / 감소·하락 / 비슷·보합. 비교 기준(`LEVEL` 외) 값은 필수(부호로 정하지 않음: "평년 대비 -0.1%, 평년과 비슷"은 `FLAT`). 숫자 없이 방향만 있는 문장도 1행으로 남긴다 |
| `evidence` | 값을 뽑은 문장 또는 표 이름을 그대로 짧게 |

### 뽑는 것 (품목마다)
1. 지난달 도매가격(`ACTUAL`, `LEVEL` + 전년·평년 대비). 순별·등급별 세부 가격은 뽑지 않는다
2. 이번 달 도매가격 전망(`OUTLOOK`)
3. 출하 전망: 출하량·출하면적·단수(`OUTLOOK`)
4. 생산량·재배(의향)면적 전망과 작형·유형별 값(표 포함)
5. 재고량(`ACTUAL`, 조사 기준 월). 입고량·출고량은 뽑지 않는다
6. 수입량 실적(지난달)과 전망(이번 달)
7. 반입량이 문장에 나오면 `ARRIVAL`

### 표현 규칙 (2016~2026 양식에서 확인)
- 보합 표현: `보합`→`FLAT`, `약보합`→`DOWN`, `강보합`→`UP`, `비슷`·`평년 수준`→`FLAT`
- 범위는 %도 범위로: "전년 대비 -12.2~-10.7%" → `value_low: -12.2, value_high: -10.7`
- 부분 기간 실적은 기간을 그대로: "3월 25일 기준 수입량" → `target_end: 03-25`
- 일평균 반입량은 단위 `톤/일`
- 본문 문장(반올림)과 표 값이 다르면 **표 값**(예: 본문 "9% 많을 것", 표 합계 8.9 → 8.9)
- 같은 사실에 시나리오가 둘이면(예: 마늘 재배면적 "면적 조절 전/후") **전망 문장이 채택한 값**만 뽑고 다른 값은 `unmapped`

### 표준 결정 (2021~2024 시범 16호에서 갈린 것, 2026-11-17)
- **지난달 도매가격(`ACTUAL`, `LEVEL`)은 본문 문장 값**을 쓴다(예: "1,270원"). 월별 가격 시계열 표 값(1,266)은 쓰지 않는다.
  "본문과 표가 다르면 표 값"은 생산·출하·면적·재고 분석 표에만 적용한다.
- **작형 표준 표기**(이 목록 밖은 쓰지 않는다. 월동무·월동배추는 `겨울`):
  - 배추·무: `시설봄`, `노지봄`, `봄`(봄 전체), `준고랭지1기작`, `준고랭지2기작`, `고랭지`, `여름`, `가을`(문서가 "가을무"·"가을" 칸), `가을일반`(문서가 "가을일반무"), `겨울`
  - 대파: `봄`, `여름`, `고랭지`, `가을`, `겨울` / 양파: `조생종`, `중만생종` / 마늘: `난지형`, `한지형`, 가격은 `깐마늘`
  - 수입: `신선`(신선○○ 수입량), 환산 합계는 `null`
- **출하 경로 구분**(산지/저장 출하, "저장 겨울" 칸)은 작형이 아니다 → `unmapped`. 그 달 출하 표에 작형 칸이 하나뿐이면 `crop_type: null`(그 달 전체).
- **재고·저장(`STOCK`)**: 월말 재고량은 `ACTUAL`, 대상 기간 = 그 월. 작기 저장량·저장의향량(예: 겨울배추 저장량 8만 5천 톤)은 대상 기간 = 연산 01-01~12-31, 입고가 끝났으면 `ACTUAL`, 아니면 `OUTLOOK`. 같은 블록의 표·그림에 연산이 적혀 있으면 그 연산.
- **수확이 끝난 작기의 실측 생산량·단수·면적**(예: "2021년 노지봄배추 생산량 26만 1천 톤", 입고 완료)은 `ACTUAL`. 수확 전이면 `OUTLOOK`.
- **"평년 수준"·"전년 수준"인데 표에 숫자가 있으면** 숫자를 넣고 `FLAT`.
- **양파 월말 재고량은 `crop_type: null`**(표 제목이 "중만생종양파 재고량"이어도). 저장 양파는 사실상 중만생종뿐이다.
- **시나리오가 둘**이면 요약 표(또는 표지)에 실린 쪽을 채택한다. 요약에 없으면 전망 문장이 채택한 쪽.
- **요약 표와 본문 방향이 다르면 본문**을 따르고 evidence에 요약 표기를 적는다.
- **표에만 있고 문장이 없는 비교 값**은 값의 부호로 `direction`을 정한다(0은 `FLAT`). 문장이 있으면 문장이 우선("비슷" → `FLAT`).
- **"전월 하순 대비"·"전주 대비"** 같은 비표준 기준은 `unmapped`.
- 같은 호 안에서 오타로 보이는 숫자(본문 5,605ha, 표 5,065ha이고 증감률이 표와 맞음)는 증감률과 맞는 쪽을 쓰고 evidence에 적는다.

### 텍스트 PDF를 텍스트로 읽을 때
- 2단 레이아웃이라 pdftotext 결과에서 **표 칸 순서가 밀릴 수 있다**(2020-04호 겨울대파 잔여면적 증감률이 한 칸씩 밀려 나옴).
- 표에서 뽑은 값은 PDF 페이지 이미지로 대조한다. 문장 속 값은 텍스트로 충분하다.

### 어디서 뽑나
- 값은 **품목 본문**에서 뽑는다. 마지막 쪽 **요약 표는 뽑지 않고 검산에만 쓴다**: 요약 표의 가격 전망·면적 전망 값이 본문에서 뽑은 값과 같아야 한다(다르면 본문 다시 확인).

### 뽑지 않는 것
- 지난 여러 달의 가격·수입량 시계열 표(우리는 KAMIS·원천 자료로 이미 가지고 있음)
- 생육 조사 비율, 소비 조사, 구매 의향 조사, 기상 전망
- 실험 품목이 아닌 품목(건고추 등)

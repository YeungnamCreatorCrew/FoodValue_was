## 작업 개요

- KREI 신규 월보 36호(엽근채소 18호·양념채소 18호), 수치 JSON 총 2,000행을 추가합니다.
- 공통 날짜 처리와 날짜 메타데이터 정정 서비스를 추가합니다. DB 스키마 및 수치 JSON 계약은 변경하지 않습니다.
- 표지 판권에 제한한 공통 파서로 열 혼입을 처리하고, 모델용 보수적 이용 후보를 `max(API 등록시각, PDF 인쇄일의 서울 자정 표현)`으로 계산합니다. API 원문·인쇄일/근거·계산 후보/상태는 원본 payload에 구분합니다.

## 검증 결과

- 기존 83개·5,989행과 신규 36개·2,000행 JSON을 보존했고 공통 파서 검증을 통과했습니다.
- 119호의 API 메타데이터와 정확한 SHA의 PDF 119호를 대조했습니다. 미보유였던 8780·8786도 공식 URL에서 기존 SHA와 같은 원본을 확보했으며 인쇄일은 모두 2026-11-03입니다.
- native 판권 83호·기존 OCR 28호·판권 부분 OCR 8호로 인쇄일 119호를 확인했습니다. SHA·표지 페이지·텍스트 해시·검토 상태를 검증하는 선택적 근거 재사용과 119호 회귀 자료를 추가했습니다. 기본 CLI가 OCR을 자동 실행하는 것은 아닙니다.
- 날짜 불일치는 5호입니다. 이번에 확인한 로컬 DB에서 기준일이 바뀐 호는 8583 하나입니다.
- 관련 회귀 검사 210개 통과. 격리 복원 DB에서 오류 시 전체 rollback, 동일 정정 재실행 0건 변경, 8583 공통 적재기 재실행의 수치 보존과 삭제 0건을 확인했습니다.
- 로컬 개발 DB의 전체 백업·격리 복원 후 날짜 메타데이터만 정정했습니다. 원본 36행에 구분 메타데이터를 추가했고, published_at은 원본 1행과 수치 41행만 변경했습니다. 수치·관계·전체 행 수 및 DB 스키마/Flyway 이력은 유지했습니다. 운영·공유 DB에는 적용하지 않았습니다. 이번 보류 항목 재점검에서는 기존 로컬 DB 날짜가 새 후보와 일치해 추가 DB 변경은 0건입니다.

## PDF 8583 날짜 처리 결과와 남은 한계

- 인쇄일 `2025-07-04`, API 원문 등록 `2025-07-02T16:05:59+09:00`을 각각 보존합니다.
- `통권발행·편집인/원장제1319호 2025년한두봉7월발행처4일 발행`처럼 통권 표식과 날짜 사이에 다른 열의 문자가 끼는 경우를 공통 로직으로 처리했습니다. PDF ID 하드코딩은 없습니다.
- 검증한 로컬 DB에서 원본 1행·연결 수치 41행의 published_at과 payload.available_from을 `2025-07-04T00:00:00+09:00`으로 맞췄습니다. 수치 JSON을 바꾸거나 실제 DB에서 재적재하지 않았습니다.
- **7월 4일 자정은 PDF 인쇄일의 프로젝트상 표현이며 실제 최초 공개 시각의 증거가 아닙니다.** 과거 버전/당시 공개 여부는 별도 검증이 필요하고 이번 수정만으로 일괄 STRICT 학습 승인하지 않습니다.
- API 등록일이 인쇄일보다 늦으면 API 시각을 쓰며, 늦은 재등록일도 버려 과거로 소급하지 않습니다. 인쇄일 미확인은 PROVISIONAL_API_ONLY로 명시합니다.

## PDF 8705 비교값 보류

5월 말 겨울무 재고의 전년 비교 후보 1건은 본문과 그래프 불일치 때문에 계속 제외했습니다. 임의 값을 생성하거나 JSON·DB에 추가하지 않았고 review_queue의 `HELD_OUT_NOT_LOADED`, `use_for_training: false` 기록을 유지합니다. 별도 연산의 작기 저장량 40,200톤·전년비 15.5%와는 다른 대상입니다.

# KREI 신규 월보 36호 데이터 및 검증 안내

KREI 농업관측센터 공식 월보 중 기존 TODO에 기록된 2025-03~2026-10의 36호를 정리했습니다. 엽근채소 18호(배추·무), 양념채소 18호(양파·마늘·대파)이며, 신규 JSON은 총 **36개·2,000행**입니다. 기존 PDF 20호를 공식 ID/URL·SHA·크기로 확인해 재사용하고, 없는 16호만 수집했습니다. 기존 팀원 JSON 83개·5,989행과 신규 JSON 36개·2,000행의 수치 데이터는 그대로 보존했습니다. 후속 날짜 처리 작업에서는 공통 수집기의 판권 추출·이용 가능 후보 계산을 수정하고 관련 회귀 테스트와 날짜 정정 서비스를 추가했습니다. DB 스키마와 공통 수치 적재기·JSON 계약은 변경하지 않았습니다.

## 포함 파일

- `verification_manifest.csv`: UTF-8 BOM의 36행 요약. PDF/JSON SHA·URL·행 수·발행일·공개 및 버전 근거.
- `manifest/verification_manifest.json`: 상세 검증 및 시점 근거. 환경마다 달라지는 DB 내부 ID와 접속 정보는 포함하지 않습니다.
- `manifest/review_queue.json`: 불명확해 제외한 비교 후보 1건. 학습에 사용하지 않습니다.
- `TODO_COMPLETED.ko.md`: 원래 TODO를 수정하지 않고 작성한 완료 대조표.
- [`date_handling_20261118/REPORT.ko.md`](date_handling_20261118/REPORT.ko.md): 후속 날짜 처리 변경, 119호 점검, 백업·격리 복원 및 로컬 DB 날짜 정정 결과.
- [`date_handling_20261118/date_audit119.json`](date_handling_20261118/date_audit119.json): 119호의 API 등록일·인쇄일·이용 후보와 점검한 로컬 DB의 수정 전후 비교.
- [`date_handling_20261118/imprint_evidence119.json`](date_handling_20261118/imprint_evidence119.json): SHA와 표지 페이지에 연결된 119호 판권 원문·추출 방법·검토 기록 및 공식 PDF 2호 확보 결과.
- [`date_handling_20261118/PR_BODY_DATE_UPDATE.ko.md`](date_handling_20261118/PR_BODY_DATE_UPDATE.ko.md): 날짜 처리 결과를 반영하기 위한 PR 본문 수정안.

공통 적재기에서 호별 JSON을 읽는 경로는 `data/krei_values/{묶음코드}/{pdf_id}.json`입니다. 부속 manifest는 수치 적재 입력이 아닙니다. 기존 83개를 포함하는 와일드카드 재적재를 하지 마세요.

## 검증 범위

36호·432쪽 전체의 기존 이미지 검토와 텍스트/OCR 대조 기록을 기준으로 수치·단위·부호·품목·작형·기간을 확인했습니다. 모든 신규 JSON과 기존 83개는 공통 파서를 통과했습니다. 최초 수치 검증의 관련 테스트는 19개였고, 후속 날짜 수정의 76개 검사에 119호 판권 근거와 SHA 불일치·숨은 텍스트 충돌 등의 회귀 검사를 추가해, 최종 KREI·날짜·공통 수집기·격리 DB 검사 **210개가 모두 통과**했습니다. 현재 DB 스키마와 호환되며, 앞선 로컬 개발 DB 읽기 전용 비교에서 적재기 변환 후 2,000행의 필드 차이가 0건이었습니다.

후속 날짜 정정은 전체 백업과 격리 복원·롤백·멱등성 검증을 거친 뒤 **작업자의 로컬 개발 DB에만** 적용했습니다. 원본 36행에 구분된 날짜 메타데이터를 추가했고, `published_at`이 바뀐 것은 PDF 8583의 원본 1행·연결 수치 41행입니다. 수치 내용·단위·비교 기준·대상 기간·연결 관계·행 수는 유지했고, 실제 개발 DB에서 JSON 재적재나 Flyway를 실행하지 않았습니다. **이 로컬 수정이 팀원·운영·공유 DB에도 적용됐다는 뜻은 아닙니다.**

날짜 점검은 JSON **119개·7,989행** 전부에 대해 완료했습니다. 미보유였던 PDF 8780·8786은 공식 다운로드 URL에서 확보했고, PDF ID·URL과 기존 JSON/manifest의 SHA-256이 정확히 일치했습니다. 두 표지의 인쇄일은 모두 **2026-11-03**입니다. 이전 자료를 덮어쓰거나 다른 버전으로 대체하지 않았습니다.

119호의 날짜 근거는 native 표지 텍스트 **83호**, 기존 OCR 표지 텍스트 **28호**, 판권 부분만 확대한 새 OCR **8호**로 구분합니다. 이전 자동 추출 실패 34호와 신규 확인 2호의 판권을 원본 이미지와 대조했고, 인쇄일 미확인은 0호입니다. 7654는 숨은 이전 호 판권 텍스트와 보이는 판권이 달라, 보이는 표지의 **2021-03-31**을 판권 부분 재인식과 이미지 대조로 확인했습니다.

[`imprint_evidence119.json`](date_handling_20261118/imprint_evidence119.json)에 PDF SHA·표지 1쪽·원문 텍스트/해시·검토 상태·기대 인쇄일을 묶었습니다. 공통 수집기의 선택 인자 `cover_evidence`로 명시적으로 전달한 근거만 재사용하며, SHA·호 식별자·페이지·텍스트 해시 불일치나 유효한 native 날짜와의 충돌은 거부합니다. 기본 CLI가 OCR 엔진을 자동 실행하거나 이 manifest를 자동 적재하는 것은 아닙니다.

이번 추가 점검에서는 기존 로컬 DB의 날짜가 새 후보와 모두 일치해 **추가 DB 변경 0건**입니다. 미등록 기존 83호는 새로 적재하지 않았습니다. 초기 `verification_manifest.csv`와 `manifest/verification_manifest.json`은 최초 검증 당시 기록으로 보존했으므로, 최신 날짜 결과는 `date_handling_20261118/`의 보고서·119호 대조표·판권 근거를 함께 확인하세요.

스키마 통과만으로 원문 정확성이나 역사 시점 사용이 자동 승인되는 것은 아닙니다. 독립적인 사람의 전수 감사나 추출 재현율 100%를 주장하지 않습니다. 건고추·양배추·당근, 입출고 계획, 소비/생육 조사, 지역 한정 촬영 자료 등은 공통 규칙에 따라 제외했습니다. 제외 사유는 `unmapped`와 review_queue에 보존했습니다. `evidence`의 p.N은 PDF 인쇄 쪽수이며, URL로 받은 원본의 SHA를 확인한 뒤 대조합니다.

## 날짜 처리 수정 및 로컬 정정 완료: PDF 8583

- 2025-07 엽근채소 PDF 8583의 인쇄 발행일은 **2025-07-04**, API 원문 등록시각은 **2025-07-02T16:05:59+09:00**입니다. API 등록 원문은 덮어쓰지 않았습니다.
- 표지의 `통권발행·편집인/원장제1319호 2025년한두봉7월발행처4일 발행`처럼 통권 표식과 날짜 사이에 다른 열의 문자가 혼입되는 경우를 공통 로직으로 처리하도록 수정했습니다. PDF 8583 하드코딩 없이 첫 페이지 판권의 제한된 구역에서만 복구하고, 본문·등록번호 날짜와 잘못되거나 중첩된 날짜를 임의로 채택하지 않도록 회귀 검사했습니다.
- 보수적 이용 가능 후보는 **`available_from = max(API 등록시각, PDF 인쇄일의 서울 자정 표현)`**입니다. 원본 payload에 `reg_date`/`api_registered_at`, `imprint_date`/`imprint_raw`, `available_from`/정책/상태를 구분하고, 기존 `published_at` 후보와 연결 수치의 날짜를 일치시킵니다. 늦은 재등록일도 버려 과거로 소급하지 않습니다.
- 백업·격리 복원 검증 후 **작업자의 로컬 개발 DB에서 원본 observation 1행과 연결 수치 41행의 `published_at`을 `2025-07-04T00:00:00+09:00`으로 정정 완료**했습니다. 원본 `payload.available_from`도 같은 후보입니다. 동일 정정 재실행의 추가 변경은 0건이며 수치 JSON은 바꾸지 않았습니다.
- **팀원 DB에는 이 정정을 적용하지 않았습니다.** 각 환경의 적용 여부와 원본·연결 수치의 날짜 일관성을 별도로 확인해야 하며, 날짜 수정만을 위해 전체 JSON을 재적재하지 마세요.
- **7월 4일은 PDF 인쇄일이며 실제 최초 공개 시각으로 검증된 값이 아닙니다.** 서울 자정은 날짜만 있는 원천을 표현하는 프로젝트 규칙입니다. 인쇄일 미확인 시에는 `UNCONFIRMED` / `PROVISIONAL_API_ONLY`로 API 임시 후보임을 명시하며, 두 날짜의 최댓값 계산만으로 역사적 공개·원본 버전·과거 학습 승인을 증명하지 않습니다.

manifest의 CSV `exploratory_assumed_available_plus_7d` / JSON `exploratory_available_from_with_7_day_lag`는 보수적인 연구 가정입니다. +7일 지연도 최초 공개나 원본 버전 동일성의 증거가 아닙니다. PDF 8553은 5월호 표지와 인쇄 발행일 4월 2일이 다르고, 8721은 인쇄일과 API 등록일이 다릅니다. 원문 기재값을 고치지 않고 각 시점을 구분했습니다.

## 보류 유지: PDF 8705 비교 후보

8705 p.5의 5월 말 겨울무 재고는 본문이 전년과 비슷하다고 하지만 그래프는 2025년산 9,246·2024년산 5,220으로 불일치합니다. 현재 절대량 9,246톤만 포함하고 해당 전년 비교 후보 1건은 JSON·DB에 넣지 않았습니다. 임의 증감률도 만들지 않았으며 review_queue에 `HELD_OUT_NOT_LOADED`, `use_for_training: false`로 기록했습니다. 별도의 작기 저장량 40,200톤·전년비 15.5% 행과 혼동하지 마세요.

## 가격 시계열 결합 및 재적재 주의

월보만으로 모델의 X/y 행렬이 완성되지 않습니다. 가격 정답 시계열을 따로 준비하고 품목·작형·대상 기간·당시 이용 가능 시점을 연결해야 합니다. ACTUAL은 월보에 실린 과거 실적이고 OUTLOOK은 전망이며, 전망값을 정답 y로 사용하지 않습니다. 일반 마늘 공급 전망을 깐마늘 가격으로 취급하거나 품목별 단위를 강제로 통합하지 않습니다. 같은 사실의 본문·표·요약 반복을 중복 집계하지 않습니다.

방향만 있는 300행은 수치가 NULL입니다. 범위 38행 중 32행의 중앙값은 적재기 파생값이며 원문 경계는 value_low/value_high로 보존합니다. NULL을 0이나 평균으로 채우지 않습니다. 연산 YYYY-01-01~12-31은 계약상의 연산 표현이며 실제 수확 기간이 아닙니다.

전체 자료를 STRICT 학습 승인으로 해석하지 않습니다. 같은 SHA의 과거 전체 원본과 공개 근거를 함께 확인하고 `strict_current_content_known_by` 이전 기준일로 소급하지 않습니다. 8517·8573의 과거 원본 일치 증거도 확인 시점이 발행일보다 늦습니다. 2026년 16호의 과거 원본 버전은 이번 수집만으로 검증되지 않았습니다.

공통 적재기는 한 JSON을 해당 원본 버전의 전체 사실로 취급하여 기존 사실을 upsert하고 누락 행은 삭제할 수 있습니다. 팀원 환경에서도 적재 전 대상·백업·기존값을 확인하고, 날짜 수정만을 위해 전체 데이터를 무조건 재적재하지 마세요. 원본 PDF·ZIP·DB 백업·개인 감사·모델 실험 파일은 이 PR에 포함하지 않습니다.

JSON의 `json_sha256`은 Git에 저장되는 UTF-8·LF 바이트 기준입니다. Windows checkout이 CRLF로 바꾸었다면 줄바꿈을 LF로 정규화한 뒤 확인하세요. PDF SHA-256은 줄바꿈 등 어떤 변환도 하지 않은 원본 PDF 바이트의 해시입니다.
